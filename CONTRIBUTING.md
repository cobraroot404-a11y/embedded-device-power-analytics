# Contributions

This repository is maintained as a personal educational and portfolio
project.

Unsolicited pull requests, code contributions, feature implementations,
documentation changes, and other external contributions are not currently
accepted.

Issues may be used for discussion or reporting where enabled, but submitting
an issue does not grant permission to copy, modify, redistribute, or reuse
the source code.

Any future contribution arrangement must be explicitly agreed to by the
repository owner in advance.
